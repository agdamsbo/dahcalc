# Changelog

## dahcalc 2026.11.1

Package to easily calculate and visualise distribution of days-at-home
during a specified time window after hospital admission. This package
supports the white-paper outlined here:
<https://github.com/monash-neurointervention/uia-dah30>

- Initial CRAN submission. For this first release focus has been on
  creating an easy-to-use pipeline with robust data aggregation and
  meaning full summary statistics. Next up is support for different data
  layouts for easy data management.
